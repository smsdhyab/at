# بكجات المسافرون العرب

إضافة ووردبريس واحدة، بلا أي اعتماد على إضافات أخرى، ولا تعدّل ملفات القالب.

## ماذا تضيف

| العنصر | أين تجده |
|---|---|
| نوع منشور **البكجات** بحقوله الـ18 | قائمة لوحة التحكم اليمنى |
| تصنيف **الوجهات** | تحت قائمة البكجات |
| صفحة بكج منسّقة (سعر، حقائق، برنامج يومي، يشمل/لا يشمل، أسئلة، أزرار واتساب) | تلقائياً على كل بكج تنشره |
| شريط سعر ثابت أسفل الشاشة في الجوال | تلقائياً |
| قائمة بكجات مع فلترة (وجهة / مدة / فئة) | كود مختصر `[aat_packages]` |
| نموذج طلب عرض سعر (الأسئلة الخمسة) → واتساب | كود مختصر `[aat_quote_form]` |
| خيارات الفئات الثلاث لنفس البرنامج | تلقائياً عبر حقل «كود البرنامج» |

## التركيب

1. اضغط مجلد `alarab-packages` كاملاً في ملف ZIP.
2. لوحة التحكم ← **إضافات ← أضف جديد ← رفع إضافة** ← اختر ملف الـ ZIP ← تثبيت ← تفعيل.
3. **إعدادات ← إعدادات البكجات** ← ضع رقم الواتساب (الافتراضي 905013196750).
4. **الإعدادات ← الروابط الدائمة** ← احفظ (بدون تغيير) مرة واحدة، حتى تعمل روابط البكجات.

## الأكواد المختصرة

| الكود | الاستعمال |
|---|---|
| `[aat_packages]` | كل البكجات مع الفلترة — لصفحة «البكجات» |
| `[aat_packages count="6" filters="no"]` | أحدث 6 بكجات — للصفحة الرئيسية |
| `[aat_packages destination="trabzon"]` | بكجات وجهة واحدة — لصفحة الوجهة |
| `[aat_quote_form]` | نموذج طلب عرض السعر |

## الفئات الثلاث من برنامج واحد

انشر ثلاثة بكجات بنفس **كود البرنامج** (مثلاً `north-7`) واختر لكل واحد فئة مختلفة
(اقتصادي / مميز / VIP). تظهر الثلاثة تلقائياً كخيارات في أعلى كل صفحة منها،
والزائر ينتقل بينها بنقرة واحدة.

## حقول البرنامج اليومي

اترك **سطراً فارغاً** بين كل يوم والذي يليه. أول سطر في كل يوم هو عنوانه:

```
اليوم الأول: الوصول والاستقبال
استقبال من مطار طرابزون ثم التوجه إلى الفندق واستلام الغرف.

اليوم الثاني: أوزنجول
انطلاق صباحاً إلى بحيرة أوزنجول ومرتفعات حيدر نبي.
```

## حذف الإضافة

الحقول محفوظة كـ post meta والبكجات كنوع منشور — إلغاء التفعيل لا يحذف أي بيانات.
