# بوت المسافرون العرب

أداة تشغيل داخلية على تليغرام: تبني عرض السعر، وتحسب ثلاثة أسعار من برنامج واحد،
وتحفظ العروض، وتعدّل أسعار الفنادق والسيارات والجولات.

**المرحلتان الأولى والثانية — مكتملتان.** المرحلة القادمة: النشر على الموقع.

من داخل المحادثة يخرج لك بضغطة واحدة: **ملف PDF** بهويتك، و**صورة** جاهزة
للواتساب والإنستغرام، و**رسالة نصية** — كلها من قالب واحد ومن نفس الأرقام.

## التشغيل أول مرة

```bash
npm install
cp .env.example .env      # ثم املأ سطرين فقط
npm run migrate           # ينشئ الجداول ويعبّئ الوجهات الأربع بأسعار ابتدائية
npm run dev
```

### ما يجب أن يكون في `.env`

| المتغيّر | من أين | إلزامي |
|---|---|---|
| `TELEGRAM_TOKEN` | `@BotFather` ← `/newbot` أو `/token` | نعم |
| `ALLOWED_IDS` | معرّفك ومعرّفات فريقك من `@userinfobot`، مفصولة بفاصلة | نعم |
| `DB_FILE` | مسار ملف قاعدة البيانات — الافتراضي `./data/aat.db` | لا |

**لا توجد قاعدة بيانات خارجية.** القاعدة ملف SQLite واحد تديره Node بنفسها
(`node:sqlite` مدمجة منذ الإصدار 22.5). لا حساب، ولا رابط اتصال، ولا خدمة تتعطّل.
النسخة الاحتياطية = نسخ الملف.

**البوت يتجاهل تماماً أي رسالة من معرّف غير مُدرج في `ALLOWED_IDS`** —
لا يرد ولا يكشف عن نفسه، ويسجّل المعرّف في السجل فقط.

## الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `/quote` | عرض سعر جديد: وجهة ← ليالٍ ← مسافرون ← موسم ← جولات ← ثلاثة أسعار ← PDF أو صورة |
| `/rates` | تعديل أسعار الفنادق والسيارات والجولات وخدمات الوجهة |
| `/recent` | آخر عشرة عروض أنشأتها |
| `/stats` | عدد العروض وقيمتها وربحها ونسبة نجاحها خلال 30 يوماً |
| `/cancel` | إلغاء ما أنت فيه |

## الفحص

```bash
npm test          # 21 فحصاً: التسعير + قاعدة بيانات حقيقية + توليد PDF وصورة
npm run typecheck # فحص الأنواع لكل الملفات
```

`npm test` هو الحارس على المال. يغطي شيئين:

- **محرك التسعير** — كل مبلغ محسوب يدوياً ومقارَن بالمخرج. إن انحرف رقم واحد يفشل.
- **المسار الكامل** — قاعدة بيانات حقيقية في الذاكرة بالمخطط والبيانات نفسها:
  قراءة الأسعار ← توليد العروض الثلاثة ← الحفظ ← القراءة ← التقارير.
- **تسرّب الأرباح** — يفشل الفحص إن ظهر رقم تكلفة أو ربح واحد في مستند الزبون،
  أو إن ظهرت هوية شركة غير هويتك.

## قواعد ثابتة في هذا المشروع

1. **كل المبالغ أعداد صحيحة بالسنت.** لا يوجد عدد عشري عائم في أي مبلغ يُحفظ أو
   يُعاد. `0.1 + 0.2 !== 0.3` غير مقبول في نظام يحسب أرباحاً.
2. **الموسم يُحسب مرة واحدة.** الفنادق تحمل سعرين حقيقيين من عقد المورّد
   (عادي / مرتفع)، والبوت يختار الصحيح ويمرّر `season: 'normal'` للمحرك.
   معامل الموسم في المحرك مخصص للاستخدام اليدوي حين لا تتوفر أسعار موسمية.
3. **نسخة الزبون لا تحمل تكلفة ولا ربحاً أبداً.** `customerOffer()` للزبون،
   و`internalBreakdown()` لك وحدك.
4. **بلا مكتبات إلا ما يلزم.** `grammy` للتواصل مع تليغرام و`puppeteer-core`
   لتوليد المستندات. قاعدة البيانات وتشغيل TypeScript وإطار الفحص من Node نفسها.
5. **قالب واحد لمخرجين.** نفس ملف HTML يُطبع PDF ويُصوَّر PNG — لا تصميم مرتين
   ولا اختلاف في الهوية بين المستند والصورة.

## توليد المستندات

يحتاج متصفحاً. على ويندوز يُكتشف Chrome أو Edge تلقائياً؛ داخل الحاوية
يُثبَّت Chromium من apt. لو لم يجد متصفحاً يقول ذلك صراحة في رسالة الخطأ.

الخطوط تُحمَّل من Google Fonts وقت التوليد، وخطوط نوتو داخل الحاوية احتياط
إن انقطع الاتصال.

⚠️ **قبل أول إرسال لزبون:** املأ حقول `BRAND_*` في `.env`. ما يُترك فارغاً
لا يُطبع — والمستند بلا اسم قانوني ولا رقم رخصة أضعف أمام الزبون.

## النشر

```bash
docker build -t aat-bot .
docker run -d --env-file .env -v aat-data:/data --restart unless-stopped aat-bot
```

يعمل بالاستطلاع الطويل، فلا يحتاج منفذاً مفتوحاً ولا عنواناً عاماً ولا شهادة TLS
ولا استثناءً في Cloudflare. أي خادم صغير يكفي.

⚠️ **`-v aat-data:/data` إلزامي.** قاعدة البيانات ملف داخل الحاوية، وبدون قرص
ثابت تضيع كل العروض والأسعار عند أول إعادة نشر. على Railway أو Fly.io اربط
قرصاً (volume) على المسار `/data`.

### النسخ الاحتياطي

```bash
docker run --rm -v aat-data:/data -v "$PWD:/out" alpine cp /data/aat.db /out/backup.db
```
